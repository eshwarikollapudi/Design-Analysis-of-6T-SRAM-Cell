# Design-Analysis-of-6T-SRAM-Cell
**Design &amp; Analysis of 6T SRAM Cell** is a CMOS-based VLSI project that designs and evaluates a conventional 6T SRAM cell using Cadence Virtuoso and Spectre. The project analyzes read/write operations, transistor sizing, Voltage Transfer Characteristics (VTC), and Static Noise Margin (SNM) to optimize stability, speed, and power efficiency.
